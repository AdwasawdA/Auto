# Robot Inference Service

YOLO-based inference service for robot vision. Receives video frames via WebSocket, runs object detection, and returns detection results.

## Features

- **Real-time object detection** using YOLOv8
- **WebSocket-based communication** for low-latency frame processing
- **Configurable detection parameters** (confidence threshold, target classes)
- **GPU acceleration** support (CUDA/TensorRT on Jetson Nano or PC)
- **Human tracking** optimized for person detection
- **Async architecture** for handling multiple concurrent operations

## Installation

### Using uv (recommended)

```bash
# Install uv if you haven't already
curl -LsSf https://astral.sh/uv/install.sh | sh

# Sync dependencies and create virtual environment automatically
uv sync

# Activate the virtual environment
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
```

**Note:** `uv sync` automatically:
- Creates a virtual environment if it doesn't exist
- Installs all dependencies from `pyproject.toml`
- Generates a lockfile (`uv.lock`) for reproducible builds

### Manual installation (without uv)

```bash
pip install websockets opencv-python numpy ultralytics pillow python-dotenv
```

## Configuration

1. Copy the example environment file:
```bash
cp .env.example .env
```

2. Edit `.env` with your settings:
   - `DEVICE`: Set to `cuda:0` for GPU or `cpu` for CPU-only
   - `MODEL_PATH`: Choose YOLO model (yolov8n.pt for speed, yolov8l.pt for accuracy)
   - `CONF_THRESHOLD`: Confidence threshold (0.0-1.0)

## Usage

### Start the inference service

```bash
# With uv (runs in the managed environment)
uv run python inference_service.py

# Or activate venv first, then run
source .venv/bin/activate
python inference_service.py
```

The service will:
1. Load the YOLO model
2. Start WebSocket server on port 8765
3. Wait for connections from robot clients

### Message Protocol

**Client sends frame:**
```json
{
  "type": "frame",
  "frame_id": 123,
  "data": "base64_encoded_jpeg_image"
}
```

**Server responds with detections:**
```json
{
  "type": "inference_result",
  "result": {
    "timestamp": 1234567890.123,
    "frame_id": 123,
    "inference_time_ms": 15.5,
    "image_shape": [480, 640],
    "detections": [
      {
        "class_id": 0,
        "class_name": "person",
        "confidence": 0.87,
        "bbox": [100, 150, 300, 450],
        "bbox_center": [200, 300]
      }
    ]
  }
}
```

**Heartbeat:**
```json
{
  "type": "ping"
}
```

Server responds:
```json
{
  "type": "pong",
  "timestamp": 1234567890.123
}
```

**Update configuration:**
```json
{
  "type": "config",
  "conf_threshold": 0.6
}
```

## Model Selection

YOLOv8 models (from fastest to most accurate):

| Model | Size | Speed (GPU) | Speed (CPU) | Use Case |
|-------|------|-------------|-------------|----------|
| yolov8n.pt | 6MB | ~5ms | ~50ms | Jetson Nano, real-time |
| yolov8s.pt | 22MB | ~8ms | ~100ms | Balanced |
| yolov8m.pt | 52MB | ~15ms | ~200ms | Better accuracy |
| yolov8l.pt | 87MB | ~25ms | ~400ms | High accuracy |
| yolov8x.pt | 136MB | ~40ms | ~600ms | Best accuracy |

For Jetson Nano or RPi4, use **yolov8n** or **yolov8s**.  
For desktop PC with GPU, **yolov8m** or **yolov8l** work well.

## Performance Optimization

### For Jetson Nano:
```python
DEVICE = "cuda:0"
MODEL_PATH = "yolov8n.pt"
```

Consider TensorRT optimization:
```bash
# Export model to TensorRT
yolo export model=yolov8n.pt format=engine device=0
```

### For PC with NVIDIA GPU:
```python
DEVICE = "cuda:0"
MODEL_PATH = "yolov8m.pt"  # Can use larger models
```

### For CPU-only:
```python
DEVICE = "cpu"
MODEL_PATH = "yolov8n.pt"  # Use smallest model
```

## Testing

Test the service with a simple client:

```python
import asyncio
import websockets
import json
import base64

async def test_inference():
    uri = "ws://localhost:8765"
    
    async with websockets.connect(uri) as websocket:
        # Read test image
        with open("test_image.jpg", "rb") as f:
            img_data = base64.b64encode(f.read()).decode()
        
        # Send frame
        message = {
            "type": "frame",
            "frame_id": 1,
            "data": img_data
        }
        await websocket.send(json.dumps(message))
        
        # Receive result
        response = await websocket.recv()
        result = json.loads(response)
        print(f"Detected {len(result['result']['detections'])} objects")

asyncio.run(test_inference())
```

## Troubleshooting

**CUDA out of memory:**
- Use smaller model (yolov8n instead of yolov8m)
- Reduce input image resolution on robot side

**Slow inference on Jetson:**
- Ensure power mode is MAXN: `sudo nvpmodel -m 0`
- Enable jetson_clocks: `sudo jetson_clocks`
- Use TensorRT engine instead of PyTorch model

**Connection refused:**
- Check firewall settings
- Verify server is running: `netstat -tulpn | grep 8765`
- Ensure correct IP address (use `ifconfig` or `ip addr`)
